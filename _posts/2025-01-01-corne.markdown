# Description

Le clavier est un 6x3 touches + 6 touches de pouce + 2 encodeurs rotatifs.

L'objectif est d'améliorer la rapidité et le confort en ne déplaçant que très peu les poignets et en évitant les mouvements éloignés le plus possible. (Bien évidemment, la configuration dépend aussi du plaisir de son utilisateur.)

La disposition principale est [BÉPO](https://fr.wikipedia.org/wiki/B%C3%A9po) conçue pour la langue française (équivalent anglais: DVORAK).

Ce clavier fonctionne avec différents layout accessibles en fonction des touches maintenues qui sont le plus souvent les touches accessibles lors de la position au repos :

<img class="image" src="{{ site.url }}/assets/images/corne/corne-position-repos-cropped.jpg" alt="Photo du clavier corne au repos">
<figcaption class="caption">Position des mains au repos</figcaption>

Les pouces et les index sont principalement utilisés.

### Remarques

Après quelques mois, j'ai noté différents points à régler.

- La navigation se fait à deux mains (pouce gauche + main droite), je souhaite utiliser une seule main.
- Les touches F1-F10 sont accessibles à deux mains (pouce droit + main gauche), idem, je veux une seule main.
- Je n'utilise quasiment pas le clavier numérique pour les chiffres, car je préfère les chiffres via Raise Layout cependant, l'activation du Raise Layout ne permet pas le backspace facilement, car c'est la même touche.
- Je souhaite pouvoir backspace et supp de la main gauche seule.

# V2

Pour la V2, j'ai rajouté un layout en plus, accessible via le pouce gauche touche gauche (touche GUI) où j'ai mis l'accès F1->F10. Cela m'a permis de libérer de la place pour les chiffres main gauche du Raise layout et donc de la place main droite pour la navigation. 

J'ai aussi fait quelques petites modifications pour obtenir quelque chose qui me plaît, je vais aussi tenter de beaucoup plus utilisé le pad numérique.
